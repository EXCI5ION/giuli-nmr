# Componentes de terceros

GIULI incorpora o depende de proyectos de software libre que conservan sus
respectivos derechos de autor y condiciones de licencia. Esta relación corresponde
a la serie 1.0.x; las versiones exactas se especifican en `pyproject.toml` y en los
metadatos del entorno de construcción.

| Componente | Licencia principal | Proyecto |
| --- | --- | --- |
| nmrglue | BSD de 3 cláusulas | <https://www.nmrglue.com/> |
| NumPy | BSD de 3 cláusulas y licencias compatibles para componentes incorporados | <https://numpy.org/> |
| pybaselines | BSD de 3 cláusulas | <https://github.com/derb12/pybaselines> |
| pyqtgraph | MIT | <https://www.pyqtgraph.org/> |
| PySide6, Qt y Shiboken | GPL v3 para esta distribución de GIULI | <https://www.qt.io/qt-for-python> |
| SciPy | BSD de 3 cláusulas y licencias compatibles para componentes incorporados | <https://scipy.org/> |

GIULI se distribuye bajo GPL v3 exclusivamente. El texto íntegro de esa licencia
está en `LICENSE`. Los avisos y textos completos de las demás licencias se conservan
en las distribuciones y repositorios enlazados de cada componente. Este archivo no
reemplaza ni modifica sus términos.
