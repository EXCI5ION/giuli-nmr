# Documentación de GIULI

Esta carpeta reúne la documentación de uso y la fundamentación científica de
GIULI. El contenido en Markdown puede consultarse directamente desde GitHub; las
versiones PDF se preparan para lectura, distribución y acceso desde la aplicación.

## Contenido

- [Manual de usuario 1.1.0](pdf/GIULI-manual-de-usuario-versión1.1.0.pdf):
  instalación, interfaz y flujos de trabajo.
- [Documentación científica 1.1.0 en PDF](pdf/GIULI-documentacion-cientifica-versión1.1.0.pdf):
  versión preparada para lectura y distribución.
- [Documentación científica en Markdown](SCIENTIFIC_DOCUMENTATION.md): métodos,
  ecuaciones, implementación, controles de calidad y limitaciones.
- [Alineación espectral](ALIGNMENT.md): detalle específico de los métodos de
  alineación disponibles.
- [Referencia rápida](QUICK_REFERENCE.md): ratón, teclado, formatos y exportación.

Los PDF generados se publican en [`docs/pdf`](pdf/). La documentación corresponde
al estado del código de la rama donde se encuentra; para resultados reproducibles
debe consultarse la documentación incluida en la versión concreta de GIULI usada.
